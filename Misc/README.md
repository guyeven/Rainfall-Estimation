# Misc

This folder contains auxiliary artifacts and helper code that may have supported exploratory analysis, result interpretation, or write-up preparation. These files are not part of the main rainfall-reconstruction pipeline and are not required to generate the maintained 100-patch benchmark outputs.

## Contents

- `paired_solver_analysis/`: downstream paired-comparison scripts and outputs for comparing solver results patch-by-patch. This material can be useful for checking or reproducing some statistical summaries, but the maintained pipeline is under `Compute-Link-Attenuations/HundredPatches/pipeline/`.
