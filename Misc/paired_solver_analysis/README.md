# Paired Solver Analysis

Auxiliary scripts and outputs for paired solver comparisons. This folder is kept under `Misc/` because it is not part of the main rainfall-reconstruction pipeline and is not required to generate the 100-patch benchmark outputs.

These analyses are downstream of `Compute-Link-Attenuations/HundredPatches/pipeline/` outputs and compare solvers patch-by-patch rather than only through aggregate descriptive statistics. They may be useful for checking or reproducing paired-comparison summaries used during result interpretation.
