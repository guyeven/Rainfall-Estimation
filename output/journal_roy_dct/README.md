# Journal copy with Roy DCT and Taylor diagrams

Based on `output/journal_revision/Journal.tex`. Original manuscript, reports, and input cache were not overwritten. No solver was rerun.

The experimental-results section is regenerated for seven methods and 100 patches. It contains whole-patch metrics, paired RMSE comparisons, wet/dry metrics, attenuation errors, distance plots, and three Taylor figures (normalized, physical units, and per-patch normalized clouds). A methodology subsection describes the nonlinear Roy adaptation. Existing case studies are retained and do not include Roy. Editing-note macros are suppressed in this copy.

## Interpretation

All 100 Roy runs report `success=false` and `stop_reason=max_outer` after 50 outer iterations. These are provisional, iteration-limited results of the nonlinear adaptation, not a reproduction of the original linear experiment. Charts label the method “Roy DCT (limited)”. Mean whole-patch RMSE is 3.554 mm/h, bias -2.443 mm/h, and correlation 0.165. Taylor plots omit mean bias; consult the metric table alongside them.

The generic cache objective sheet does not identify the Roy native objective. Do not interpret its generic weighted sum as the Roy objective. Solver diagnostics carry the native objective.

## Render a separate report

From the repository root, using a Python environment with Compute-Link-Attenuations/requirements.txt installed:

```sh
cd Compute-Link-Attenuations
MPLBACKEND=Agg python render_analysis_report.py \
  --cache HundredPatches/pipeline/batch_analyze_output_roy_dct/stats_report_cache.json \
  --render-config HundredPatches/pipeline/render_report_roy_dct.yaml \
  --output-dir HundredPatches/pipeline/report_roy_dct
```

This output directory is separate from the original reports. Repeating this command replaces only this Roy report. Taylor figures are generated by the manuscript builder, not the general report renderer.

## Rebuild manuscript

From the repository root (requires the original cache, saved reconstruction fields, and rendered report):

```sh
MPLBACKEND=Agg python output/journal_roy_dct/build_journal.py
latexmk -pdf -interaction=nonstopmode -halt-on-error -cd output/journal_roy_dct/Journal_with_Roy_DCT.tex
```

To compile the standalone source ZIP, extract it and run `latexmk -pdf Journal_with_Roy_DCT.tex` in its folder, or select that file as the main document in Overleaf. Standard TeX Live packages are required. The ZIP includes the Elsevier CAS class/style and bibliography style.

`provenance.json` records source/cache SHA-256 checksums, settings, convergence counts, and comparisons. `taylor_statistics.json` records the plotted values. All 700 saved fields were checked against cached whole-patch metrics. The compiled 28-page PDF was rendered and visually reviewed.
