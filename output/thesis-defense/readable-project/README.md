# Thesis defense slides

Edit document.tex. Images are separate files in images/.
The SimplePlus theme is included as readable definitions in the preamble.

Compile from this folder with a TeX installation (MacTeX or TeX Live):

```sh
latexmk -pdf document.tex
```

Alternatively upload this folder as a ZIP project to Overleaf and select document.tex as the main file.

This is the readable working copy. The separate glossary-beamer.tex in the parent folder serves the single-file editor preview.
