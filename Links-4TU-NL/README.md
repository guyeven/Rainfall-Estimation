# Links-4TU-NL

Utilities and data helpers for the 4TU-NL commercial microwave-link data source.

The link data provides realistic CML endpoints, lengths, and frequencies. In the maintained 100-patch workflow these geometries are placed into selected radar-derived patch coordinate systems, and attenuations are simulated from the corresponding rainfall fields.

`patch-map-frontend/` contains a small frontend for visual inspection of patch/link maps.
