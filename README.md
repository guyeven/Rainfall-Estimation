# Rainfall Estimation from Commercial Microwave Links

This repository contains an end-to-end workflow for building rainfall-reconstruction experiments from radar-derived rainfall patches and commercial microwave-link (CML) geometries.

## Repository Layout

- `Compute-Link-Attenuations/` contains the main numerical pipeline: forward attenuation modeling, interpolation baselines, inverse solvers, batch analysis, and report rendering.
- `Links-4TU-NL/` contains utilities and a small frontend for inspecting the 4TU-NL microwave-link data source.
- `Patch-Generator/` contains tools for selecting and inspecting radar-derived rainfall patches.
- `Link-Generator/` contains tools for generating and visualizing link geometries.
- `ITU-Calculator/` contains a small calculator for ITU-R P.838-3 rain-attenuation coefficients.
- `paired_solver_analysis/` contains auxiliary paired-comparison analyses for solver outputs.
- `Latex/` contains the compiled write-up source and generated PDF.

## Main Workflow

The current maintained benchmark workflow lives in `Compute-Link-Attenuations/HundredPatches/`.

1. Prepare or inspect the selected rainfall patches and link-overview files.
2. Run the configured solvers using `Compute-Link-Attenuations/HundredPatches/pipeline/batch_solve_config.yaml`.
3. Analyze the solver outputs with `Compute-Link-Attenuations/HundredPatches/pipeline/analyze.yaml`.
4. Render figures and spreadsheets with `Compute-Link-Attenuations/HundredPatches/pipeline/render_report.yaml`.

The pipeline uses six solver outputs: IDW, ILDW, Solver(ILDW), Convex Solver, Homotopy Solver, and Solver(GT). The `solutions/` directory is intentionally not generated by the README; it can be restored or regenerated from the batch-solve config.
