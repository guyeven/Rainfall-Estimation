# 🛑 **2. BEFORE STARTING — STOP EVERYTHING**

Open **any terminal** and run:

```bash
pkill -f uvicorn
pkill -f python
```

Close all terminals that were running servers.

This guarantees a clean start.

---

# ▶️ **3. START BACKEND #1 — Detection Server**

Used by the **Detection tab** of the UI.

### Terminal 1:

```bash
cd ~/Projects/RainfallMap/Patch-Generator/backend
source env/bin/activate       # optional if you want the venv active
uvicorn app:app --reload --host 127.0.0.1 --port 8200
```

You should see:

```
Uvicorn running on http://127.0.0.1:8200
Application startup complete.
```

### Test in browser:

`http://127.0.0.1:8200/docs`

If it loads the FastAPI documentation → OK.

---

# ▶️ **4. START BACKEND #2 — Smoothen Server**

Used by the **Smoothen tab** of the UI.

### Terminal 2:

```bash
cd ~/Projects/RainfallMap/Patch-Generator/backend
source env/bin/activate       # optional
uvicorn benchmark_app:app --reload --host 127.0.0.1 --port 8201
```

You should see:

```
Uvicorn running on http://127.0.0.1:8201
Application startup complete.
```

### Test:

`http://127.0.0.1:8201/docs`

Important:
If this does **not** load → Smoothen panel will freeze on “Loading…”.

---

# ▶️ **5. START FRONTEND UI (Vite)**

Your project uses **Vite**, not Create-React-App.

### Terminal 3:

```bash
cd ~/Projects/RainfallMap/Patch-Generator/frontend
npm install        # first time only
npm run dev
```

This starts the UI on:

```
http://localhost:5173
```

(or another port if 5173 is taken — Vite will say which).

---

# 🧪 **6. TEST THE WHOLE PIPELINE**

## ✓ Detection Tab

1. Open `http://localhost:5173`
2. Choose radar files or let backend auto-select
3. Set thresholds etc.
4. Click **Detect patches**
5. You should see patch list and details.

## ✓ Export Selection

1. Select some patches with the “Keep” button
2. Click **Export selected (JSON)**

This produces `selected_patches.json`.

## ✓ Smoothen Tab

1. Switch to **Smoothen** tab
   *(tab name formerly “Benchmark”)*
2. Load the exported JSON
3. Click **Load patches**
4. Preview three panels:

   * Raw
   * Smoothed (gaussian/b-spline)
   * Difference
5. Under each you will see:

   * **L¹**
   * **L^∞**
   * **L¹/area**

If any of these do not appear:

* Check that backend #2 prints log messages for:

  ```
  POST /benchmark/load_patches
  GET /benchmark/patch_image
  GET /benchmark/stats
  ```

# 🔍 **7. Quick Troubleshooting**

| Problem                          | Fix                                                           |
| -------------------------------- | ------------------------------------------------------------- |
| Smoothen tab stuck on “Loading…” | Smoothen backend (8201) not running                           |
| No stats under images            | `/benchmark/stats/...` failing → check backend logs           |
| Images load but blank            | HDF5 path wrong; ensure JSON contains correct `"source_file"` |
| Frontend not starting            | Use `npm run dev`, not `npm start`                            |
