# Repository documentation

This directory contains documentation that applies to the repository as a
whole rather than to one software component.

## Contents

- `artifact-storage.md` explains which large inputs and generated results are
  treated as research artifacts, how their SHA-256 manifests are created and
  verified, and how they could be migrated to an immutable external archive.

Component-specific usage instructions remain in the README files beside the
corresponding code, including `Compute-Link-Attenuations/README.md` and the
README files under `Patch-Generator/`, `Link-Generator/`, `Links-4TU-NL/`, and
`ITU-Calculator/`.
